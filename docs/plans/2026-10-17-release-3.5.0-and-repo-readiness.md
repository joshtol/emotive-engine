# Release 3.5.0 (lean per-element entries + compact textures) and repo readiness

Status: PLAN, 2026-10-17. Branch `perf/lean-electric` (local worktree `C:/zzz/emotive-lean`, NOT pushed).
Owner: Joshua Tollette. Nothing is published, tagged, pushed or deployed without the owner's explicit go-ahead.

## Why

The Emotive Engine is going on the One Thousand Drones site (About page) as a LIVE demo (crystal + electric
elemental), and the repo should be ready for the traffic that brings. While building that demo we found:

- `assets/textures/Crystal/*.png` were 10.9 MB in total (crystal.png alone 1.81 MB, 2048x2048). Re-encoded
  to 1024 px WebP: 282 KB in total, crystal 40 KB. The loader now asks for `.webp`. PNGs stay in the repo as
  sources (never in the npm package; the old example bundles under `site/public/` still reference them).
- A lean entry with ONLY the electric elemental: `dist/emotive-mascot-3d-electric.js`, export `./3d-electric`,
  249 KB brotli (all 8 elements 303 KB, base 3D 232 KB; electric costs ~17 KB). three stays a peer.
- Gotcha that cost a build: `package.json` `sideEffects` silently tree-shook the electric REGISTRATION files
  (the first lean build was byte-identical to the base). Each element's registration files must be listed.
- New options: `maxPixelRatio` (default 2.0), `hdri: false` (skips a 1.7 MB lighting file),
  `setSurface('light')` (electric arcs drawn as ink on light surfaces), `glowHalo: false` (no screen-space halo
  rectangle when the canvas bleeds past its slot).
- Known: a cold first visit stalls the main thread ~3.3 s while shaders compile (Intel UHD; warm ~0.5 s).
  The owner accepted this for now.

Commits so far on the branch: `fa7771a1` (lean electric entry + WebP textures), `22f27067` (ink on light),
`c8d917b5` (glowHalo option). Engine tests: 337 pass.
